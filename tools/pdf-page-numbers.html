PDF Page Numbers

This tool adds page numbers to every page of a PDF. You choose where the number goes, for example at the bottom in the middle, and which number to start from. You can also skip the first page, which is useful when the first page is a cover.

Choose a PDF file, pick the position, and press Add page numbers. The file stays inside your browser; it is never uploaded anywhere.
