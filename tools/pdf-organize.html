PDF Organize Pages

This tool shows you every page of a PDF as a small picture. You can move pages up or down to change their order, and delete the pages you do not need. Then the tool saves the result as a new PDF.

Choose a PDF file and wait for the page pictures to load. Use the Move up, Move down and Delete buttons under each page; everything works with a keyboard and a screen reader. When the order is right, press Save PDF. The file stays inside your browser; it is never uploaded anywhere.
