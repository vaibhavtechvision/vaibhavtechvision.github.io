PDF Compress

This tool makes a PDF file smaller so it is easier to share or upload. There are two ways to do it:

  • Smaller file: every page is turned into a picture. This gives the biggest size reduction, but the text becomes an image, so screen readers can no longer read it and you cannot select or search the text.
  • Keep text readable: the file is cleaned up and re-saved without changing how pages look. Text stays readable for screen readers, but the size reduction is usually small, especially for PDFs that are mostly scanned images.

An honest note: PDFs made of scans are already compressed pictures, so no tool can shrink them a lot without losing quality. Choose a PDF file, pick a way, and press Compress PDF. The file stays inside your browser; it is never uploaded anywhere.
