PDF Watermark

This tool stamps text, for example Draft or Confidential, diagonally across every page of a PDF. The stamp sits behind the content, light enough that the page stays readable.

Please note: the watermark text works with English letters and numbers only, not Hindi. Choose a PDF file, type the watermark text, and press Add watermark. The file stays inside your browser; it is never uploaded anywhere.
