PDF Reader

This tool reads the text inside a PDF file and shows it on the screen, so your screen reader can read it to you. You can also listen to the text aloud or save it as a plain text file.

Choose a PDF file and press Read PDF text. The file is opened inside your browser only; it is never uploaded anywhere.
